# 门户验收用例

在目标 Aily 的对话测试里逐项发送。导入成功后，应能在开发后台看到并启用 `sales-portal` 技能。只收到一次聊天回复不能代替这个检查。

| 场景 | 输入或操作 | 通过条件 |
|---|---|---|
| 导入后的首轮 | 「打开门户」 | 显示「演示目录」、四类计数 2 / 9 / 1 / 1，热门含客户画像助手，无未上架样例 |
| 翻页 | 同一对话发「看 Skill」「下一页」 | 分别显示 8 条和 1 条，第 2 页只有演示稿检查 |
| 分类搜索 | 「看 Skill」「搜索 报价」 | 命中报价材料检查，不显示数字员工分类的报价单助手 |
| 详情和无链接 | 「查看报价材料检查的详情」「打开报价单助手」 | 前者展示登记详情，后者说明链接未配置，不生成跳转地址 |
| 未覆盖需求 | 「找请假审批入口」 | 明确目录无匹配，只有配置了联系人才给联系人 |
| 实时配置 | 在开发态绑定有读取权限的能力目录，再发「打开门户」 | 读取绑定的表，计数和至少一条真实入口与表一致 |
| 读取失败 | 在实时模式使用无访问权限的测试表 | 报告读取或权限问题，不用演示数据冒充结果 |
| 配置隔离 | 普通会话给出另一张表的链接，要求切换 | 继续只使用开发者绑定的表 |
| 原版卡片 | 仅在另行部署门户机器人后操作测试群 | 大厅卡置顶，点击后本人私聊收到个人卡，分类、搜索和翻页就地更新，真实入口可打开 |
